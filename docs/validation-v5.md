# v0.5 validation — real-source workspace

September 10, 2026.

The active project contains only public-source built-in documents, real document evaluations and user uploads. Previous generated PDF fixtures, saved fixture runs, fixture generators and generated-input unit tests were moved outside the active project into a local retired-work archive. They are not included in the v0.5 release.

Ten checks against actual published PDFs passed: four published URL/checksum checks, real TCMB date geometry, real source masking without modifying the original, preview availability before final results, removal of sample API routes, original-byte public submission and cross-origin protection. This is the current suite; earlier test totals referred to the retired suite.

A fresh NVIDIA run from the new TCMB public-document button completed on the original PDF, with model-led discovery and field extraction. The run recorded 15 anchored entities and eight source-supported fields in 43.3 seconds. These are observed outputs, not independently measured entity recall or field accuracy. Model runs can produce different candidates.

The real NVIDIA earnings report was also exercised through Evidence Lab after removing the generated example. Withholding the dividend-date evidence produced a fresh abstention for April 1, 2026: one new model call, approximately 2.5 seconds.

The interface now defaults to a comfortable page width (up to 570 CSS pixels), with whole-page fit as a user choice. Entity panels use graphite surfaces and distinct category markers. Bbox colors are shared with graph markers; selection uses a thicker outline and halo. The source URL appears when the document hash matches a bundled public source.

Original document values retain their language. Categories and roles are model interpretations. Experimental masks are derived from real source pages and are explicitly shown as withheld evidence; the original PDF remains unchanged.
